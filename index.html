Each marker is one model. The bar spans the lowest to highest model (inter-model spread, not a probability range); the tick and number are the median. Click a row to show it on the map.

Values represent the median projected warming across five selected CMIP6 models. These are scenario-dependent projections, not deterministic forecasts.

Each model's warming is measured against its own 1981–2010 average, then averaged over the 20-year period. Models: ACCESS-CM2, CanESM5, GFDL-ESM4, MIROC6, MRI-ESM2-0 (run r1i1p1f1, equal weight). The colour scale is fixed at 1–7 °C for every scenario and period so colours can be compared between views. With one run per model, small near-term differences between scenarios are within natural variability.

Data: NOAA CMIP6 (Google Cloud public dataset), monthly near-surface air temperature (tas); experiments historical, ssp245, ssp585. State boundaries: Natural Earth.
